# Project Guidelines & Preferences

- **Autonomous Execution**: Jalankan semua perintah terminal, pembacaan file (`view_file`), pembuatan/pengeditan file, dan build/kompilasi secara langsung dan mandiri tanpa perlu meminta konfirmasi atau izin terlebih dahulu kepada pengguna.
- **Concise Reporting**: Laporkan progres dan hasil akhir secara ringkas, jelas, dan langsung ke intinya.
